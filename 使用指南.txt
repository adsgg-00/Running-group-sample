跑者智慧助理 使用指南
================================================================

這份指南分成兩部分：

  第一部分  操控者指南：負責開啟系統的人看，先做完這部分，使用者才能使用全部功能
  第二部分  使用者指南：跑者日常操作看

系統運作方式：

  Garmin 手錶 → Garmin Connect → intervals.icu → 本系統後端 → 儀表板網頁
                                                     ↓
                                              Groq AI（教練建議、課表）


################################################################
第一部分  操控者指南
################################################################

一、每次使用前要開什麼（最重要）
----------------------------------------------------------------
順序不能顛倒：先開後端，再開網頁。

步驟 1  確認電腦有連上網路
        圖表、地圖、Garmin 同步和 AI 都需要網路。

步驟 2  在專案資料夾（Running-group-sample）開啟終端機
        用 VS Code 開啟專案資料夾，再選「終端機 → 新增終端機」。

步驟 3  啟動後端，輸入以下指令後按 Enter：

        .\venv\Scripts\python.exe app.py

步驟 4  確認後端啟動成功
        終端機出現這行就是成功：

        Running on http://127.0.0.1:5000

        注意：這個終端機視窗要一直開著，關掉後網站就無法取得資料。

步驟 5  開啟網站
        在檔案總管雙擊 index.html，再按「前往儀表板」。
        也可以直接雙擊 challenge.html 進入儀表板。

步驟 6  確認儀表板正常
        看儀表板左下角的「設備連線狀況」：

        Garmin 已同步    一切正常，可以交給使用者
        尚未同步 Garmin  後端正常，請到「活動紀錄」按「同步 Garmin」
        後端未啟動       回到步驟 3

使用完畢要關閉時：在終端機按 Ctrl + C。


二、第一次安裝（新電腦才需要，只做一次）
----------------------------------------------------------------
1. 安裝 Python 3。

2. 在專案資料夾建立執行環境並安裝套件：

   python -m venv venv
   .\venv\Scripts\python.exe -m pip install -r requirements.txt

3. 建立設定檔：

   Copy-Item env.example .env

4. 用編輯器打開 .env，填入下一節的金鑰。

5. 到 intervals.icu 註冊，並在設定中「直接連接 Garmin」。
   不要透過 Strava 連接，從 Strava 匯入的活動無法被本系統讀取。

6. 依照第一節啟動系統，到「活動紀錄」按「同步 Garmin」。
   第一次會抓取過去一年的資料，需要等待一下。


三、.env 設定說明
----------------------------------------------------------------
  項目                    是否必填  說明
  GROQ_API_KEY            必填      AI 教練和 AI 課表使用，到 Groq 網站申請
  INTERVALS_API_KEY       必填      Garmin 資料同步使用
                                    位置：intervals.icu → Settings → Developer Settings
  INTERVALS_ATHLETE_ID    建議填    填 0 代表金鑰本人，也可填網址上的 i123456
  GROQ_MODEL              選填      不填時使用 openai/gpt-oss-120b
                                    模型下架時系統會自動改用備用模型

  STRAVA_CLIENT_ID、STRAVA_CLIENT_SECRET 目前程式沒有使用，不需要填。

重要提醒：
  - 修改 .env 後，要按 Ctrl + C 關閉後端再重新啟動才會生效。
  - .env 裡是私密金鑰，不要傳給別人，也不要上傳到 GitHub。


四、確認系統狀態
----------------------------------------------------------------
後端啟動後，用瀏覽器開啟：

  http://127.0.0.1:5000/api/health

正常會看到 status 為 ok，groq_configured 和 intervals_configured 都是 true。
true 只代表金鑰「有填」，不代表金鑰正確。
要確認金鑰有效，請實際按一次「同步 Garmin」和「取得今日建議」。


五、使用限制
----------------------------------------------------------------
  - 只能在執行後端的那台電腦上使用，手機或其他電腦連不到。
  - 系統只支援一位跑者，所有資料都來自 .env 設定的 intervals.icu 帳號。
  - 儀表板側邊欄的姓名和地區寫在 challenge.html 裡，要更換需修改該檔案。
  - AI 教練的判斷規則預設手錶為 Garmin Forerunner 235（沒有 HRV）。
    換手錶時要修改 app.py 裡的 COACH_RULES。


六、資料備份與維護
----------------------------------------------------------------
所有資料都存在專案資料夾的 running.db。

備份：先按 Ctrl + C 關閉後端，再把 running.db 複製到其他地方。

如果 running.db 遺失：
  - 重新啟動後端會自動建立空白資料庫。
  - 按「同步 Garmin」可以找回 Garmin 活動和恢復數據。
  - 手動新增的紀錄、CSV 匯入的紀錄、每日主觀感受和課表無法找回。

刪除單筆活動（網頁上沒有刪除按鈕，要由操控者處理）：

  1. 後端啟動中，開啟 http://127.0.0.1:5000/api/workouts 找到該筆的 id
  2. 開一個新的終端機，輸入（把 活動id 換成實際的 id）：

     Invoke-RestMethod -Method Delete http://127.0.0.1:5000/api/workouts/活動id

  3. 重新整理儀表板

  從 Garmin 同步的活動刪除後，下次同步可能會再回來。


七、問題排除
----------------------------------------------------------------
畫面顯示「後端未啟動」或「連不到後端」
  → 後端沒開，或終端機被關掉了。依第一節步驟 3 啟動，再重新整理網頁。

操作時跳出「Failed to fetch」
  → 後端中途停止了。查看終端機是否有錯誤，重新啟動後再試。

啟動時顯示找不到模組（ModuleNotFoundError）
  → 套件沒裝好，執行：
    .\venv\Scripts\python.exe -m pip install -r requirements.txt

啟動時顯示 Port 5000 已被占用
  → 通常是後端已經開著。先關閉其他正在執行 app.py 的終端機，再重新啟動。

「尚未設定 INTERVALS_API_KEY」或「尚未設定 GROQ_API_KEY」
  → .env 沒有填，或填完後沒有重新啟動後端。

「intervals.icu 驗證失敗，請確認 API key 與 athlete ID」
  → 檢查 .env 的 INTERVALS_API_KEY 和 INTERVALS_ATHLETE_ID。

「Groq 上找不到可用的模型」
  → 到 Groq 網站查目前可用的模型，填入 .env 的 GROQ_MODEL。

「AI 回傳的格式無法解析，請再試一次」
  → AI 偶爾會回傳錯誤格式，再按一次即可。

AI 功能顯示「伺服器錯誤」
  → 查看終端機的錯誤訊息。常見原因是 Groq 金鑰錯誤或用量已達上限。

同步後提示有活動是「從 Strava 匯入」
  → 到 intervals.icu 設定，改成直接連接 Garmin。

課表沒有出現在手錶上
  → 確認 intervals.icu 設定裡「Upload planned workouts」有勾選。
  → 在 Garmin Connect App 手動同步一次手錶；Garmin 只會收到接下來約 7 天的課表。
  → 如果手錶上的課表沒有配速目標，到 intervals.icu 的設定填入跑步的閾值配速再傳一次。

同步成功但沒有最新活動
  → 確認手錶已同步到 Garmin Connect，且 intervals.icu 上看得到該筆活動。


################################################################
第二部分  使用者指南
################################################################

一、開始使用
----------------------------------------------------------------
1. 請操控者先啟動系統（見第一部分）。
2. 開啟首頁，按「前往儀表板」。
   首頁右上角的「儀表板」按鈕，以及往下捲動後右下角的按鈕，都能一鍵前往。
3. 跑步後先讓手錶同步到 Garmin Connect App，資料才會進入系統。


二、建議的每日流程
----------------------------------------------------------------
1. 開啟儀表板，查看「訓練總覽」。
2. 在「今天感覺如何？」為四個項目各選一個分數，按「儲存今天感覺」記錄下來。
3. 按「取得今日建議」，依照 AI 教練的建議訓練。
4. 跑完後到「活動紀錄」按「同步 Garmin」，查看這次的分析。

小提醒：晚上戴著手錶睡覺，系統才有睡眠和可靠的靜止心率資料，AI 判斷也會更準確。


三、訓練總覽
----------------------------------------------------------------
【課表執行能力】看你的訓練數據

  狀態 TSB        體能減疲勞。數字越負代表累積疲勞越多，低於 -30 會變紅色
  近 7 天跑量     超過前 4 週平均的 110% 會變黃色，提醒加量過快
  強度分配        近 28 天輕鬆、中強度、高強度的比例，輕鬆跑約 80% 較理想
  有氧效率        輕鬆跑時每次心跳前進幾公尺，數字上升代表有氧能力進步

【身體日常狀態】看你的恢復情況

  靜止心率        只採用有戴錶睡覺的日子，比基準高 5 以上會變紅色
  昨晚睡眠        昨晚的睡眠時數，以及近 7 晚有幾晚戴錶
  今天感覺如何    疲勞、肌肉痠痛、睡眠品質、心情，各評 1 到 5 分
  儲存今天感覺    不用呼叫 AI 也能記錄今天的分數，同一天再儲存會覆蓋成最新分數

【今日建議】

  1. 四個感覺項目都要選分數，否則無法取得建議。
  2. 可以填寫今天原本預計的訓練，例如「間歇 800m x 6」，也可以留空。
     留空時，如果「我的課表」今天有安排，AI 會以課表內容為準。
  3. 按「取得今日建議」，AI 會給出以下其中一種結論：

     照計畫練    狀態良好，可以照原定計畫
     降低強度    建議減量或放慢
     休息恢復    今天以休息為主

  AI 建議不會保存，重新整理網頁後就會消失。
  感覺分數在按「儲存今天感覺」或「取得今日建議」時保存，重新整理後會自動帶回。
  只點分數沒有儲存，重新整理後分數就不見了，按鈕旁會顯示「有變更尚未儲存」提醒你。

【最新活動與活動分析】

  顯示路線地圖、距離、時間、配速、心率，以及心率、配速、步頻、海拔曲線和心率區間。
  在右側的「選擇活動」列表點任一筆，就能切換要查看的活動。
  列表會顯示日期、地點、距離、配速和心率，0.5 公里以下的跑步片段不會列出。
  地點取自 Garmin 活動名稱，名稱裡沒有地點時會顯示「未記錄地點」。

【本週訓練】

  從週一到週日，每天一格，顏色和文字代表當天的訓練類型：
    輕＝輕鬆跑　中＝中強度　強＝高強度　長＝長距離
    跑＝沒有心率資料的跑步　交＝交叉訓練（重訓、騎車等）　休＝休息
  強度依照心率區間自動判斷，和 AI 教練使用相同的標準。
  長距離是指單次 8 公里以上，且達到前 4 週平均週跑量 25% 的跑步。
  右上角是本週跑量和前 4 週平均，下方顯示強度課次數、最長距離和休息天數。
  出現以下情況會顯示橘色提醒：
    - 本週跑量超過前 4 週平均的 110%
    - 連續兩天高強度
    - 連續 7 天以上沒有休息
  把滑鼠移到某一天，可以看到當天的活動名稱。
  還沒練的日子會用虛線顯示「我的課表」裡的計畫，右上角也會顯示本週計畫跑量。

【訓練量統計】

  預設顯示最近 12 週的每週跑量，右上角可切換成「最近 7 天」。


四、專屬課表
----------------------------------------------------------------
【我的課表】

  頁面最上方列出接下來 14 天，每天一筆課表，重新整理後也會保留。
  點某一天的「新增」或鉛筆圖示，就能手動輸入或修改：
    日期、類型（休息、輕鬆跑、恢復跑、長距離、節奏跑、間歇、比賽、交叉訓練、其他）、
    標題、距離、時間和內容說明。
  在修改視窗按「刪除」可以移除當天的課表。
  每天只會有一筆課表，新增到已有課表的日子時，會先詢問是否取代。

【AI 產生課表】

  1. 選擇主要目標：強身健體、3K、5K、7.5K、10K、半馬或全馬。
  2. 填寫期望完賽時間或目標，例如「4小時內」、「無痛完賽」。
  3. 選擇開始日期，預設是明天。
  4. 勾選每週可訓練的日子，至少 3 天，沒勾選的日子一律排休息。
  5. 按「產生兩週課表」，AI 會依你近期的數據排出 14 天的課表。
  6. 確認預覽沒問題後，按「套用到我的課表」才會儲存。
     套用會取代這 14 天已有的課表，包含手動輸入的，畫面會先提醒。

  想換目標時按「重新設定」，預覽在套用前不會影響「我的課表」。

【傳到手錶】

  按「我的課表」右上角的「傳到手錶」，接下來 14 天的課表會送到 intervals.icu，
  再由 intervals.icu 自動同步到 Garmin Connect 和手錶（Garmin 只會收到接下來約 7 天）。
  1. 按「傳到手錶」，等畫面顯示「已傳送」。
  2. 打開手機的 Garmin Connect App 同步一次手錶。
  3. 在手錶的「訓練」或「行事曆」裡就能看到當天的課表。

  每筆課表旁的圖示：
    綠色勾勾　已傳到手錶，內容是最新的
    橘色箭頭　修改過但還沒傳，再按一次「傳到手錶」就會更新
  刪除或改成休息的課表，下次按「傳到手錶」時會從手錶上移除。
  AI 課表會帶著暖身、間歇、緩和等分段和配速或心率目標；手動輸入的課表只有總距離或時間。
  沒有填距離也沒有填時間的課表不會傳送，因為手錶需要知道什麼時候結束。

五、活動紀錄
----------------------------------------------------------------
同步 Garmin
  第一次抓取過去一年的資料，之後抓取最近 30 天。
  距離上次同步超過 6 小時，開啟儀表板時也會自動在背景同步。

查看活動
  點任一筆紀錄，就會回到訓練總覽顯示地圖和分析。

手動新增
  在「訓練總覽」右上角按「手動新增」，填寫標題、距離和時間。
  日期會記為新增當下的時間，也沒有路線和曲線資料。

匯入 CSV（Garmin 同步失敗時的備用方式）
  1. 在 Garmin Connect 網站的活動列表匯出 CSV，語言需為中文。
  2. 按「匯入 CSV」並選擇檔案。
  3. 重複的活動會自動略過。CSV 紀錄只有摘要數據，沒有路線和曲線。

七、目前還不能使用的功能
----------------------------------------------------------------
以下項目是畫面示意，操作後不會產生實際效果：

  - 首頁的搜尋框、頭像和「查看更多」目前沒有功能。


八、常見問題
----------------------------------------------------------------
Q：畫面顯示「後端未啟動」怎麼辦？
A：請操控者啟動系統，再重新整理網頁。

Q：剛跑完為什麼看不到活動？
A：先確認手錶已同步到 Garmin Connect，稍等一下再按「同步 Garmin」。

Q：為什麼靜止心率或睡眠顯示 --？
A：昨晚可能沒有戴錶睡覺，或資料還沒同步。

Q：可以用手機看嗎？
A：目前只能在執行系統的那台電腦上使用。

Q：可以刪除紀錄嗎？
A：網頁上沒有刪除按鈕，請聯絡操控者處理。

Q：AI 的建議可以完全相信嗎？
A：AI 建議僅供訓練參考，不是醫療診斷。如果疼痛持續或身體出現異常，請停止訓練並就醫。
